# 포커 딜 팀전 운영 매뉴얼

## 1. 게임 요약

| 항목 | 내용 |
| :--- | :--- |
| 인원 | 15명, 3팀 |
| 팀 | 하트팀 5명, 클로버팀 5명, 스페이드팀 5명 |
| 라운드 | 3라운드 |
| 시작 칩 | 팀당 25칩 |
| 승리 | 3라운드 종료 후 팀 총 칩 1위 |
| 핵심 | 다른 팀과 협상해 같은 숫자 조합을 만들고 개인별로 제출 |

팀원끼리는 카드 정보를 공유할 수 있지만, 거래는 반드시 다른 팀과만 한다.

---

## 2. 사용 카드

일반 트럼프에서 아래 30장만 사용한다. 다이아몬드, J, Q, K, 조커는 사용하지 않는다.

| 팀 | 고유 카드 | 비공개 카드 |
| :--- | :--- | :--- |
| 하트팀 | ♥️A~♥️5 | ♥️6~♥️10 |
| 클로버팀 | ♣️A~♣️5 | ♣️6~♣️10 |
| 스페이드팀 | ♠️A~♠️5 | ♠️6~♠️10 |

- A는 숫자 1로 본다.
- A(1)~5는 처음 배정된 플레이어의 고유 카드다. 라운드가 바뀌어도 소유자는 그대로 유지된다.
- 라운드 진행 중에는 고유 카드도 거래할 수 있으며, 라운드가 끝나면 원래 소유자에게 반환된다.
- 6~10은 각 라운드 시작 때 팀이 내부에서 정해 나누어 갖는다.
- 각 카드는 게임 안에 1장씩만 존재한다.

---

## 3. 준비물

| 준비물 | 용도 |
| :--- | :--- |
| 트럼프 카드 1벌 | 30장 사용 |
| 칩 200개 이상 | 거래, 점수 |
| 팀 표식 3세트 | 팀 구분 |
| 딜 보드 | 조합표 안내 |
| 타이머 | 라운드 시간 관리 |
| 기록지 또는 스프레드시트 | 점수, 제출, 거래 기록 |
| 거래소 자리 | 거래 처리 |

---

## 4. 시작 세팅

1. 15명을 3팀으로 나눈다.
2. 각 팀에 25칩과 10장의 카드를 지급한다.
3. 팀별 고유 카드 A(1)~5를 플레이어 5명에게 1장씩 배정한다.
4. 고유 카드는 모두가 볼 수 있게 공개한다.
5. 딜 보드, 타이머, 거래소, 기록지를 준비한다.

---

## 5. 라운드 진행

| 단계 | 내용 | 시간 |
| :---: | :--- | :---: |
| 1 | 팀별 비공개 카드 6~10 내부 분배 | 5분 |
| 2 | 협상, 거래, 개인 제출 | 각 라운드 10분 |
| 3 | 제출 확인, 패널티 적용, 팀 점수 정산 | 제한 없음 |

- 라운드 시작 전에 팀별로 비공개 카드 6~10을 나누어 갖는다. 이 과정은 팀 내부에서 자유롭게 진행한다.
- 한 라운드가 끝나면 카드 상태를 리셋한다.
- 고유 카드 A(1)~5는 라운드 중 거래되었더라도 라운드 종료 시 원래 소유자에게 반환한다.
- 비공개 카드 6~10은 회수 후 각 팀이 새 라운드마다 내부에서 다시 정해 나누어 갖는다.
- 협상, 거래, 개인 제출은 모두 라운드 협상 시간 10분 안에 완료해야 한다. 10분이 지나면 제출은 인정되지 않는다.

---

## 6. 조합표

| 조합 | 조건 | 보상 |
| :--- | :--- | :---: |
| 원 페어 | 같은 숫자 카드 2장 | 2칩 |
| 트리플 | 같은 숫자 카드 3장 | 7칩 |

예:

```text
♥️4 + ♣️4 = 원 페어
♠️9 + ♥️9 + ♣️9 = 트리플
```

한 카드로 여러 조합을 동시에 제출할 수 없다.

---

## 7. 협상과 거래

- 거래는 다른 팀 플레이어와만 가능하다.
- 같은 팀원끼리는 거래할 수 없다.
- 팀원끼리는 카드 정보와 전략을 자유롭게 공유할 수 있다.
- 거래는 거래소에서 진행자 앞에서만 인정한다.
- 1:1 거래만 허용한다.
- 플레이어 1명은 한 라운드에 최대 2회 거래할 수 있다.
- 두 플레이어가 함께 거래소에 와서 한 번 처리하면, 거래 내용과 관계없이 두 플레이어 모두 거래 1회로 기록한다.
- 고유 카드와 비공개 카드는 모두 거래할 수 있다.
- 한 번의 거래에서 카드 1장을 팔거나 살 수 있다.
- 칩은 함께 주고받을 수 있으며, 칩 개수에는 제한을 두지 않는다.
- 카드나 칩이 실제로 넘어간 뒤에는 거래를 취소할 수 없다.
- 카드 정보 판매, 블러핑, 거짓 협상은 허용한다.
- 다른 팀 카드를 강제로 보거나 빼앗는 행동은 금지한다.

---

## 8. 개인 제출

제출은 팀 단위가 아니라 개인 단위다.

각 플레이어는 현재 자기가 가지고 있는 카드들 중에서 조합을 만들고, 만들 수 있는 조합들 중 1개의 조합만 선택해 제출할 수 있다. 같은 팀원 카드와 합쳐서 제출할 수 없다.

- 제출은 라운드 협상 시간 10분 안에 해야 한다. 10분이 지난 뒤의 제출은 인정하지 않는다.
- 한 라운드에 제출 기회는 1번뿐이다.
- 유효한 조합을 제출하지 못하면 -1칩 패널티를 받는다.
- 거래를 한 번도 하지 않으면 -2칩 패널티를 받는다.
- 카드 거래를 하지 않았고 조합도 제출하지 못한 경우에는 두 패널티가 동시에 적용되어 -3칩을 받는다.

---

## 9. 정산

라운드 정산은 개인 결과를 계산한 뒤 팀별로 합산한다.

```text
팀 라운드 순이익
= 팀원 5명의 제출 보상 합계
- 조합 미제출 패널티 합계
- 거래 0회 패널티 합계
```

예:

```text
P1 트리플 = +7칩
P2 원 페어 = +2칩
P3 제출 없음, 거래 0회 = -3칩
P4 원 페어 = +2칩
P5 제출 없음, 카드 거래 1회 = -1칩

팀 라운드 순이익 = +7칩
```

팀 보유 칩은 마이너스가 될 수 있다. 정산 결과 팀 총 칩이 0칩 아래로 내려가면 음수 칩으로 기록한다.

라운드 종료 후 공개할 내용:

- 팀별 라운드 순이익
- 팀별 현재 총 칩
- 필요 시 개인 제출 결과와 패널티

비공개 카드 위치와 거래 후 카드 보유 정보는 공개하지 않아도 된다.

---

## 10. 승리 조건

3라운드 종료 후 팀 총 보유 칩이 가장 많은 팀이 승리한다.

동점이면 아래 순서로 결정한다.

1. 총 트리플 제출 수가 많은 팀
2. 마지막 라운드 획득 칩이 많은 팀
3. 공동 우승

## 13. 빠른 체크리스트

게임 시작 전:

- [ ] 15명 3팀 편성
- [ ] 팀당 25칩 지급
- [ ] 고유 카드 A(1)~5 배정 및 공개
- [ ] 딜 보드, 타이머, 거래소, 기록지 준비

각 라운드:

- [ ] 팀별 비공개 카드 6~10 전달
- [ ] 카드 확인 5분 진행
- [ ] 협상, 거래, 제출 시간 진행
- [ ] 개인 제출과 거래 횟수 확인
- [ ] 패널티 적용 후 팀 점수 정산
- [ ] 카드 상태 리셋: 고유 카드는 원래 개인에게 유지, 비공개 카드만 회수

게임 종료:

- [ ] 팀 최종 칩 합산
- [ ] 동점 조건 확인
- [ ] 우승 팀 발표
